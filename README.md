# Sprintly Analytics Dashboard BI

Interactive single-page analytics dashboard built with HTML, CSS, and JavaScript.

## Overview

This project is a responsive business intelligence dashboard for Sprintly. It provides a compact view of customer growth, product usage, retention, revenue opportunities, and executive insights in a single static web page.

## Features

- Business overview KPIs
- Monthly customer signup visualization
- Subscription plan distribution
- Acquisition channel analysis
- Company size breakdown
- Product usage and adoption metrics
- Customer engagement scatter chart
- Customer health and retention table
- Revenue and conversion opportunity analysis
- 12-month revenue forecast
- Scenario Lab for what-if analysis
- Filters
- Table search and sorting
- CSV export
- Dark mode
- Responsive desktop and mobile layout

## Run Locally

No build step is required.

1. Download or clone the repository.
2. Open `index.html` in a web browser.

## Deploy to Vercel

This project can be deployed as a static site.

1. Push this repository to GitHub.
2. Log in to Vercel.
3. Click **Add New → Project**.
4. Import this GitHub repository.
5. Set **Framework Preset** to `Other`.
6. Leave **Build Command** empty.
7. Leave **Output Directory** empty.
8. Click **Deploy**.

Because `index.html` is located at the repository root, Vercel can serve the dashboard directly.
